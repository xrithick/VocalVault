Quick 2-minute Setup:
  1. Open your project at supabase.com
  2. Go to SQL Editor → run the SQL script from schema.sql.
  3. Go to Project Settings → API → copy your Project URL and anon (public) key.
  4. Paste them below and click Connect & Test.
